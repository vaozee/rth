Konfigurasi

Pengaturan Portal

Sambungkan Google Apps Script agar unggah, edit, dan baca dokumen tersimpan langsung di Google Drive.

Koneksi Google Apps Script

Deploy kode Code.gs yang disertakan sebagai Web App di akun Google Drive-mu, lalu tempel URL-nya di sini. Setelah tersambung, unggah/edit/tulis artikel akan tersimpan langsung ke folder Drive yang kamu tentukan.

Belum tersambung
Dapatkan URL ini setelah deploy di script.google.com → Deploy → New deployment → Web app.
